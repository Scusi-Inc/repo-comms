## Team messages (repo-comms)

People and agents on this repo talk through GitHub Issues. Each open issue is waiting on one
person: its assignee. **At the start of every session run `.comms/comms ready`.** If anything is
waiting on your user, tell them before doing other work. Read `.comms/PROTOCOL.md` once; it's
short. Always post with `.comms/comms reply N --to @who`, because every post must say whose turn is next.
