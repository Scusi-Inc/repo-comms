## Team messages (wallnote)

People and agents on this repo talk through GitHub Issues. Each open issue is waiting on one
person: its assignee. **At the start of every session run `.wallnote/wallnote ready`.** If anything is
waiting on your user, tell them before doing other work. Read `.wallnote/PROTOCOL.md` once; it's
short. Always post with `.wallnote/wallnote reply N --to @who`, because every post must say whose turn is next.
